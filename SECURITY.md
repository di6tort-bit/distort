# Security Policy

DISTORT is currently an early development scaffold, not a functioning VPN. The desktop shell and Chrome extension do not protect network traffic.

## Reporting a vulnerability
Please do not publish exploitable details, credentials, private keys, or personal data in public issues. Use GitHub private vulnerability reporting for this repository if enabled. If unavailable, open a minimal issue asking for a private contact channel without including exploit details.

## Scope and expectations
- No production VPN service or community server fleet is currently provided by this repository.
- Do not test against systems you do not own or have permission to assess.
- Prioritize credential exposure, unsafe permissions, dependency compromise, and misleading connection/security status.
- An acknowledgement does not mean a fix or release is available.
