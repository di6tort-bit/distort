DISTORT — Windows + Chrome Preview
==================================

IMPORTANT
---------
This is an early UI preview, NOT a working VPN. It does not tunnel traffic,
change your IP address, or provide DNS/IP leak protection. Do not rely on it
for privacy or security.

REQUIREMENTS
------------
- Windows 10/11 for the desktop app
- Node.js 20.11+ (LTS recommended)
- npm (included with Node.js)

RUN DESKTOP PREVIEW
-------------------
1. Install Node.js from https://nodejs.org/
2. Double-click start.bat, or run these commands in the repository folder:
     npm install
     npm start

LOAD CHROME EXTENSION PREVIEW
-----------------------------
1. Open chrome://extensions
2. Enable Developer mode
3. Click "Load unpacked"
4. Select the apps\extension folder

The extension does not request proxy permissions and does not route browser traffic.

BUILD WINDOWS INSTALLER
-----------------------
Run build-exe.bat, or use:
     npm install
     npm run dist:win

The intended output folder is release\. The installer build has not yet been
verified on a Windows runner.

WHAT IS NOT AVAILABLE
---------------------
The VPN engine, configured servers, tunnel driver/service, browser proxy,
kill switch, DNS/IP leak protection, control plane, and community server fleet
are not implemented. No server is seeded or available by this preview.

See docs\V1-IMPLEMENTATION.md and docs\ROADMAP.md.
